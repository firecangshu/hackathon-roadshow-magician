# 项目简介 · 黑客松路演魔术师

**黑客松路演魔术师**是一个专为黑客松和竞赛场景设计的路演全链助手。它能把任意成果的源代码或项目资料，通过7步交互式工作流，一键转换为竞赛级的路演材料。

工具覆盖8类路演场景（竞赛Demo、投资路演、技术答辩、产品推广、电梯演讲、展位展示、技术讲课、资源对接），支持19种产物输出（从赛前提报到赛后传播），并提供六维版本矩阵（时长、侧重、风格、格式、语言、团队），让不同场景、不同受众都能获得匹配的路演材料。

核心设计遵循"先勾选，后生成"原则：用户先选择需要的产物和版本，工具再精准生成，避免无效产出浪费时间和算力。所有流程在本地完成，不联网、不外传，适用于国内开发环境。

**Project Brief · Hackathon Roadshow Magician**

Hackathon Roadshow Magician is an all-in-one roadshow assistant built for hackathons and competitions. It transforms any project source code or materials into competition-grade pitch decks through a 7-step interactive workflow.

The tool covers 8 roadshow scenarios, supports 19 deliverable types across 5 stages, and offers a 6-dimensional version matrix. Its core principle is "select first, generate later" — users pick what they need before any output is produced, saving time and compute. Fully local, no cloud required.
